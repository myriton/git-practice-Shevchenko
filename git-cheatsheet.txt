# ШПАРГАЛКА

1. ПРОВЕРКА И НАСТРОЙКА Git
git version
Показывает версию установленного Git.

git config --global user.name "ваш_ник"
Устанавливает имя пользователя для всех репозиториев.

git config --global user.email "ваша_почта@example.com"
Устанавливает email.

Проверить настройки:
git config --list

2. СОЗДАНИЕ И ИНИЦИАЛИЗАЦИЯ РЕПОЗИТОРИЯ
mkdir git-practice-Shevchenko
Создаёт папку проекта.

cd git-practice-Shevchenko
Переход в папку проекта.

pwd
Показывает текущий путь.

ls
Показывает содержимое текущей папки.

git init -b main
Инициализирует локальный репозиторий с веткой main.
Создаёт скрытую папку .git со служебными файлами

3. СОСТОЯНИЕ И ИНДЕКС 
git status
Показывает состояние репозитория:

git add <файл>
Добавляет конкретный файл в индекс.

git add .
Добавляет ВСЕ файлы (кроме игнорируемых) в индекс.

4. КОММИТЫ
git commit -m "сообщение коммита"
Создаёт коммит с описанием изменений.

git log
Полная история коммитов: хеш, автор, дата, сообщение.
Выход — клавиша q (если внизу появился ":" — это pager less).

git log --oneline
Компактная история: короткий хеш + сообщение.

git show <хеш>
Детали конкретного коммита: автор, дата, сообщение и diff — какие строки добавлены (+) или удалены (-).

5. РАБОТА С ВЕТКАМИ
git branch
Список локальных веток. Звёздочка (*) — текущая.

git branch -a
Все ветки: локальные + удалённые (remotes/origin/...).

git switch -c new-feature
Создаёт ветку new-feature и сразу переключается на неё.

git switch main
Переключается на существующую ветку main.

git switch -
Переключается на предыдущую ветку.

git branch -d hotfix
Безопасное удаление ветки (только если смержена).

git branch -D new-feature
Принудительное удаление ветки, даже если не смержена.

6. УДАЛЁННЫЙ РЕПОЗИТОРИЙ
git remote add origin <URL>
Привязывает локальный репозиторий к удалённому.

git remote -v
Показывает адреса для fetch и push.
    
git push -u origin main
Отправляет ветку main на сервер и связывает её с origin/main.
Флаг -u позволяет дальше писать просто git push.

git push --set-upstream origin new-feature
Отправляет новую ветку new-feature и связывает её.

git push
Отправляет изменения в уже отслеживаемую ветку.

git pull
Забирает изменения с сервера и сливает с локальной веткой.

git fetch --all
Забирает информацию обо всех ветках (без слияния).

git fetch --prune
Убирает ссылки на ветки, которых уже нет на сервере.

git push origin --delete new-feature
Удаляет ветку на сервере (локально остаётся).

# ПРИМЕРЫ

git remote add origin https://github.com/myriton/git-practice-Shevchenko.git
git remote -v
git switch main
git push -u origin main
git switch new-feature
git push --set-upstream origin new-feature

# ПРОБЛЕМЫ
error: branch 'new-feature' not found
Причина: ветка не создана или уже удалена.
Решение: git branch -a — посмотреть реальный список.
