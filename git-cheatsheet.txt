# Шпаргалка

1. ПРОВЕРКА И НАСТРОЙКА
git version
Показывает версию установленного Git.

git config --global user.name "ваш_ник"
Устанавливает имя пользователя для всех репозиториев.

git config --global user.email "ваша_почта@example.com"
Устанавливает email для всех репозиториев.

2. СОЗДАНИЕ И ИНИЦИАЛИЗАЦИЯ РЕПОЗИТОРИЯ
mkdir git-practice-Shevchenko Создаёт папку проекта.

cd git-practice-Shevchenko
Переход в папку проекта.

pwd
Показывает текущий путь.

git init -b main
Инициализирует локальный репозиторий с основной веткой main.
Создаёт скрытую папку .git со служебными файлами.

3. СОСТОЯНИЕ И ИНДЕКС (STAGING)
git status
Показывает состояние репозитория:
- какие файлы изменены
- какие файлы в индексе
- какие ещё не отслеживаются (Untracked)

git add <файл>
Добавляет конкретный файл в индекс.

git add .
Добавляет ВСЕ файлы (кроме игнорируемых) в индекс.

4. КОММИТЫ
git commit -m "сообщение коммита"
Создаёт коммит с описанием изменений.

git log
Полная история коммитов: хеш, автор, дата, сообщение.
Выход из просмотра: клавиша q.

git log --oneline
Компактная история: сокращённый хеш + сообщение.

git show <хеш_коммита>
Детальная информация о конкретном коммите

5. РАБОТА С ВЕТКАМИ
git branch
Список локальных веток. Звёздочка (*) — текущая ветка.

git branch -a
Все ветки: локальные + удалённые (remotes/origin/...).

git switch -c new-feature
Создаёт новую ветку new-feature и сразу переключается на неё.

git switch main
Переключается на существующую ветку main.

git switch -
Переключается на предыдущую ветку.

git branch -d hotfix
Безопасное удаление ветки (только если смержена).

git branch -D new-feature
Принудительное удаление ветки (даже если не смержена).

6. УДАЛЁННЫЙ РЕПОЗИТОРИЙ (GitFlic / GitHub)
git remote add origin <URL_репозитория>
Привязывает локальный репозиторий к удалённому.

git remote -v
Показывает адреса удалённых репозиториев (fetch и push).

git push -u origin main
Отправляет ветку main на сервер и связывает её с origin/main.
После этого достаточно писать просто git push.

git push --set-upstream origin new-feature
Отправляет новую ветку new-feature на сервер и привязывает её к origin/new-feature.

git push
Отправляет изменения в уже отслеживаемую ветку.

git pull
Забирает изменения с сервера и сливает их с локальной веткой.

git fetch --all
Забирает информацию обо всех ветках с сервера (без слияния).

git fetch --prune
Обновляет информацию и удаляет ссылки на ветки, которых уже нет на сервере.

git push origin --delete new-feature
Удаляет ветку new-feature на сервере (локально она остаётся).

7. ФАЙЛ .gitignore
.gitignore
Специальный файл, в котором перечисляются файлы и папки, которые Git должен игнорировать.

# Примеры

mkdir git-practice-Shevchenko
cd git-practice-Shevchenko
git init -b main
git status 
git add .
git commit -m "Initial commit: add README"
git log --oneline

# Проблемы
error: branch 'new-feature' not found
Причина: ветка с таким именем не существует.
Решение: посмотреть список веток командой git branch -a
и использовать правильное имя.
